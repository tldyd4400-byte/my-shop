# 어믜뜰 네이버 플레이스 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈페이지 V4와 동일한 최신 사실을 네이버 스마트플레이스 기본정보·대표키워드·예약 소개에 반영하고 잘못 선택된 방문접수/출장만 해제한다.

**Architecture:** 먼저 정확한 게시 문구를 저장소의 운영 문서로 고정하고, 네이버 관리자 화면에서 현재 값을 다시 읽어 차이를 기록한다. 입력과 미리보기까지 준비하되 공개 정보를 바꾸는 저장 버튼 직전에 사용자에게 변경 내용을 보여주고 별도 승인을 받는다. 저장 후 공개 플레이스에서 반영 상태를 검증한다.

**Tech Stack:** 네이버 스마트플레이스, 네이버 예약 파트너센터, Codex 내장 브라우저 Computer Use, Markdown 운영 문서

## Global Constraints

- `방문접수/출장`만 해제한다.
- 사용자 요청에 따라 `비건 메뉴`, `카운터석`, `연인석`, `휠체어 이용 가능 화장실`, `콜키지 무료`, `테이크아웃 할인` 선택은 유지한다.
- 홈페이지에는 실제로 없는 바 형태 카운터석을 표시하지 않는다.
- 네이버의 공개 상세설명·키워드·예약 상품 문구 수정은 제3자에게 보이는 외부 변경이므로 저장 직전에 사용자 확인을 받는다.
- 로그인 비밀번호, OTP, 보안문자는 사용자가 직접 처리한다.
- 네이버의 경고, 검수 안내 또는 예상치 못한 필수 제출 요구가 나타나면 저장하지 않고 사용자에게 보고한다.
- 홈페이지 production 배포 승인과 네이버 플레이스 저장 승인은 서로 독립적으로 받는다.
