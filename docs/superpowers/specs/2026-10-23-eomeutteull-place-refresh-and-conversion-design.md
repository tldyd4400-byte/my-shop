## 8. 검색 노출과 AEO/GEO

### 검색어 사용 원칙

- 제목, 본문, FAQ에 자연스럽게 배치한다.
- 지역명과 키워드를 기계적으로 반복하지 않는다.
- 하나의 문단에서 같은 키워드를 불필요하게 되풀이하지 않는다.
- 방문자가 궁금해하는 질문에 먼저 답한다.

### 주요 질문형 콘텐츠

- 청주에서 50명 이상 회식이 가능한 식당인가요?
- 어믜뜰은 통대관이 가능한가요?
- 청주갈비찜 가격과 주문 조건은 어떻게 되나요?
- 아이와 함께 먹을 수 있는 메뉴가 있나요?
- 주차와 휠체어 이용이 가능한가요?
- 포장 메뉴와 할인 가격은 어떻게 되나요?

### 구조화 데이터

- Restaurant
- Menu와 MenuItem
- FAQPage
- BreadcrumbList
- WebSite
- Article 또는 BlogPosting

Restaurant 스키마에는 최신 영업시간, 주소, 전화, 가격대, 예약 URL, 주차·접근성 정보를 넣는다. 리뷰 평점은 출처와 최신성 요건을 충족할 때만 사용한다.

### 검색 엔진 갱신

- `sitemap.xml`의 주요 페이지 `lastModified`를 실제 배포 시점에 맞춰 갱신한다.
- 배포 후 Google Search Console과 네이버 서치어드바이저에서 주요 URL 재수집을 요청한다.
- 검색 노출은 보장하지 않으며 콘텐츠 정확성, 기술 신호, 클릭·예약 행동을 개선한다.

## 9. 데이터 구조

매장 정보와 메뉴를 한 곳에서 관리한다.

- `STORE`: 상호, 주소, 전화, 영업시간, 휴무, 주차, 접근성, 단체 규모
- `MENU_CATEGORIES`: 대표 세트, 곁들임, 추가, 포장
- `MENU_ITEMS`: 가격, 설명, 조건, 대표 여부, 포장 여부

- 리뷰 수집 API가 실패해도 기존 승인 후기는 유지한다.
- 네이버 예약 URL이 바뀌면 한 곳의 상수만 수정한다.
- 지도 임베드가 차단되면 네이버 지도 링크와 정적 위치 이미지를 제공한다.
- 영상 로딩이 실패하면 대표 사진과 동일한 핵심 문구·CTA를 표시한다.
- 네이버와 홈페이지 값이 다르면 네이버 관리자 확인 후 수정한다.

## 14. 검증 기준

### 콘텐츠

- 17개 메뉴 이름·가격·조건이 네이버와 일치한다.
- 영업시간, 브레이크타임, 라스트오더, 휴무일이 일치한다.
- 최대 52명, 통대관 협의, 무료 주차가 주요 전환 영역에 표시된다.
- 홈페이지에 바 형태 카운터석을 실제 시설처럼 표시하지 않는다.
- 비건 안내가 완전 비건 조리를 보장하는 표현이 아니다.

### 기능

- 모든 네이버 예약 버튼이 현재 운영 중인 예약 상품으로 이동한다.
- 전화 CTA가 대표번호로 연결된다.
- 메뉴·매장·위치·후기·모임 가이드 링크가 정상 작동한다.
- 모바일 고정 CTA가 화면을 가리지 않는다.

### 품질

- lint, typecheck, unit/integration test, production build를 통과한다.
- 데스크톱과 모바일 주요 화면을 시각 검수한다.
- Lighthouse 또는 동등한 검사를 통해 성능·접근성·SEO 회귀를 확인한다.
- sitemap, robots, canonical, Open Graph, JSON-LD를 확인한다.
- 실제 운영 URL에서 주요 경로와 예약 링크를 다시 확인한다.

3. 로컬 데스크톱·모바일 검수

5. 홈페이지 배포 최종 승인
6. Vercel 배포 및 운영 URL 검증
7. 네이버 플레이스 변경 필드와 문구 별도 제시
8. 네이버 저장 직전 최종 승인
9. 네이버 저장 후 반영 상태 확인

## 16. 범위 제외

- 네이버 방문자 리뷰 비공식 스크래핑
- 네이버 정보를 무단으로 자동 수정하는 기능
- 결제 또는 예약을 홈페이지 내부에서 직접 처리하는 기능
- 별도 CMS 또는 신규 데이터베이스 도입
- 검색 순위나 추천 노출 보장
- 확인되지 않은 시설·메뉴·혜택의 홈페이지 표기

## 17. 승인된 핵심 결정

- V4 범위는 최신 정보, 검색 노출, 예약 전환 강화다.
- 네이버 플레이스 관리자 정보가 운영 사실 확인의 우선 기준이다.
- 방문접수/출장은 해제 대상으로 한다.
- 비건 메뉴, 카운터석, 연인석 등 사용자가 유지 요청한 네이버 선택값은 그대로 둔다.
- 홈페이지는 실제 운영 사실만 정확하게 표현한다.
- 구현과 배포는 별도 최종 승인을 거친다.
