# 어믜뜰 청주갈비찜·모임회식 검색 성장 설계

## 1. 목표

기존 `청주 등갈비찜` 검색 강점을 유지하면서 다음 검색 의도로 노출 범위를 확장한다.

- `청주갈비찜`, `청주 갈비찜 맛집`, `청주 매운갈비찜`
- `청주 모임 장소`, `청주 단체 식당`, `청주 회식 장소`
- 보조 목표: `청주 가족외식`, `청주 부모님 식사`, `청주 아이와 식당`

검색 유입 이후 방문자가 메뉴와 단체 이용 조건을 확인하고 전화 상담 또는 네이버 예약으로 이동하는 흐름을 만든다. 특정 검색 순위나 노출 시점은 보장하지 않는다.

## 2. 확인된 매장 근거

- 어믜뜰 등갈비찜 청주봉명동본점
- 12테이블, 총 52석
- 한 팀 최대 52명 이용 가능
- 52명 이용 시 매장 통대관 가능
- 통대관의 고정 최소 인원·최소 금액 조건은 없음
- 날짜, 시간, 인원은 매장과 사전 협의
- 6인 단체석 2테이블
- 건물 뒤 무료 지상주차장
- 매운 등갈비찜과 간장 등갈비찜 선택 가능
- 30여 종 셀프바와 수제우유빙수 제공
- 네이버 예약과 전화 문의 가능

변동될 수 있는 가격, 영업시간, 주차 및 예약 정보는 배포 직전에 다시 확인한다.

## 3. 검색 의도와 페이지 역할

| 페이지 | 중심 검색 의도 | 역할 |
| --- | --- | --- |
| `/` | 청주 봉명동 맛집, 청주 등갈비찜 | 브랜드·메뉴·모임 가능성을 연결하는 전체 허브 |
| `/menu` | 청주갈비찜, 청주 매운갈비찜 | 맛 선택, 가격, 구성, 먹는 순서를 설명하는 메뉴 대표 페이지 |
| `/store` | 어믜뜰 매장, 청주 단체 식당 공간 | 실제 공간, 좌석, 주차와 브랜드 근거 |
| `/stories/cheongju-group-dining` | 청주 모임 장소, 청주 회식 장소 | 단체 이용과 통대관을 설명하는 모임·회식 대표 가이드 |
| `/stories/family-dining-guide` | 청주 가족외식 | 아이·부모님 동반에 필요한 메뉴와 편의 정보 |
| `/faq` | 단체예약, 통대관, 주차, 예약 | 방문 전 질문에 직접 답하는 AEO 보조 페이지 |

페이지마다 한 가지 중심 의도를 맡겨 서로 경쟁하는 중복 문서를 만들지 않는다.

## 4. 화면·콘텐츠 설계

### 4.1 홈페이지

- 현재 영상 중심 히어로와 등갈비찜 메시지는 유지한다.
- 중간 영역에 `청주 모임·회식 안내` 카드 또는 배너를 추가한다.
- 핵심 근거로 `최대 52명`, `통대관 가능`, `날짜·인원 사전 협의`, `무료주차`를 표시한다.
- 모임·회식 가이드, 전화 문의, 네이버 예약으로 연결한다.

### 4.2 메뉴 페이지

- 페이지 제목과 첫 화면에서 `청주갈비찜` 의도를 자연스럽게 명확히 한다.
- 매운 등갈비찜과 간장 등갈비찜을 맛, 추천 대상, 구성 관점에서 비교한다.
- 기존 가격, 셀프바, 네 단계 식사 경험은 유지한다.
- 회식 참석자 중 매운 음식을 못 먹는 사람도 간장 메뉴를 선택할 수 있음을 안내한다.
- 단체 예약 가이드로 이어지는 행동 버튼을 추가한다.

### 4.3 모임·회식 가이드

첫 화면에서 다음 정보를 즉시 답한다.

> 어믜뜰은 소규모 식사 모임부터 최대 52명의 단체 회식까지 이용할 수 있습니다. 52명 단체는 매장 통대관으로 진행할 수 있으며, 날짜와 인원은 매장과 사전에 협의해 주세요.

구성은 다음과 같다.

1. 최대 52명과 통대관 안내
2. 실제 좌석과 매장 전체 공간
3. 매운맛·간장맛 선택과 단체 식사 구성
4. 셀프바와 수제우유빙수까지 이어지는 식사 경험
5. 주차와 오시는 길
6. 단체 예약 진행 방법
7. 전화 상담과 네이버 예약 행동

고정된 최소 인원, 최소 금액 또는 확정되지 않은 별도 혜택은 표시하지 않는다.

### 4.4 가족외식 가이드

- 가족외식 검색 의도만 담당하도록 범위를 명확히 한다.
- 간장 등갈비찜, 유아의자, 부드러운 등갈비, 주차, 후식 빙수를 실제 근거와 사진으로 설명한다.
- 모임·회식 가이드와 중복되는 통대관 설명은 링크 수준으로 제한한다.

### 4.5 FAQ

다음 질문을 추가하거나 보완한다.

- 단체는 최대 몇 명까지 이용할 수 있나요?
- 매장 통대관이 가능한가요?
- 통대관 조건은 어떻게 확인하나요?
- 단체 이용 시 메뉴를 어떻게 고르면 되나요?
- 단체 방문 시 주차할 수 있나요?

답변은 짧고 직접적으로 작성하며 실제 운영 조건만 사용한다.

## 5. 검색 구조

- 각 페이지에 고유한 `title`, `description`, canonical URL, Open Graph 정보를 제공한다.
- 페이지마다 하나의 명확한 H1을 사용한다.
- Restaurant 구조화 데이터의 메뉴 URL, 예약 가능 여부, 음식 유형과 실제 매장 정보를 점검한다.
- FAQ 구조화 데이터는 화면에 실제 표시되는 질문과 답변만 반영한다.
- 홈페이지, 메뉴, 매장, FAQ, 모임 가이드를 문맥이 자연스러운 내부 링크로 연결한다.
- 사이트맵에 신규 가이드를 포함하고 배포 후 구글과 네이버에 재수집을 요청한다.
- 검색어 반복이나 지역명 나열보다 실제 사진, 좌석 수, 예약 방식과 식사 경험을 중심으로 작성한다.

## 6. 네이버 플레이스·외부 신뢰 신호

- 네이버 플레이스 소개에 갈비찜, 단체모임, 회식, 최대 52명 통대관 정보를 사실에 맞게 반영한다.
- 대표 사진은 음식, 전체 좌석, 단체 배치, 주차장, 셀프바, 빙수 순으로 구성한다.
- `최대 52명 단체 회식 및 통대관 안내` 새 소식을 게시한다.
- 홈페이지와 네이버 플레이스의 상호, 주소, 전화, 영업시간, 가격, 주차 및 예약 정보를 일치시킨다.
- 방문자에게 키워드를 강요하거나 대가성 리뷰를 요구하지 않고 실제 식사·공간 경험이 담긴 솔직한 리뷰를 안내한다.
- 구글 비즈니스 프로필과 외부 맛집 정보도 동일한 사실로 유지한다.

## 7. 사진 우선순위

1. 매장 전체 좌석이 보이는 가로 사진
2. 여러 테이블을 단체석으로 구성한 사진
3. 6인 단체 테이블 사진
4. 여러 명의 음식이 함께 차려진 한 상 사진
5. 건물 뒤 주차장과 매장 입구 사진
6. 음식·셀프바·빙수의 식사 흐름 사진

손님 얼굴이 식별되는 사진은 당사자 동의를 받은 경우에만 사용한다. 신규 사진이 준비되기 전에는 기존 실제 매장 사진을 사용하고 이후 교체한다.

## 8. 행동과 측정

- 검색 유입 → 메뉴/모임 정보 확인 → 전화 또는 네이버 예약의 흐름으로 설계한다.
- `group_inquiry_click`, `phone_click`, `naver_reservation_click`, `naver_map_click`을 페이지와 버튼 위치별로 기록한다.
- 메뉴, 모임, 가족 검색어 묶음을 분리해 28일 단위로 노출, 클릭, 랜딩페이지 방문과 문의 행동을 비교한다.
- 검색엔진 수집과 평가 시간을 고려해 배포 직후의 일시적 순위보다 8~12주 추세를 기준으로 판단한다.

## 9. Pencil 승인과 배포 절차

1. 프로젝트 최상단 `초안`에 홈페이지, 메뉴, 모임·회식 가이드, FAQ 변경안을 먼저 스케치한다.
2. 사용자가 Pencil 스케치를 승인한다.
3. 테스트를 먼저 작성하고 코드를 구현한다.
4. 접근성, 모바일·데스크톱 화면, 메타데이터, 구조화 데이터, 링크와 분석 이벤트를 검증한다.
5. Vercel 미리보기에서 최종 확인 후 운영 배포한다.
6. 사이트맵을 확인하고 구글·네이버에 신규·변경 페이지 수집을 요청한다.
