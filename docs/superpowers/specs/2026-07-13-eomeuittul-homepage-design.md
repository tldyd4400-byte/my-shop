# 어믜뜰 공개 홈페이지 구현 명세

## 목표

현재 Next.js 기본 시작 화면을 `초안`과 `DESIGN.md`에 정의된 어믜뜰 등갈비찜 청주봉명동본점의 반응형 공개 홈페이지로 교체한다. 이번 범위는 취미·테스트용 공개 홈페이지이며 관리자 로그인과 대시보드는 구현하지 않는다.

## 선택한 접근

Pencil 초안의 데스크톱 1440px 및 모바일 390px 구성을 충실히 구현한다. 음식과 매장 사진 슬롯에는 테스트용으로 제작한 이미지를 사용한다. 이 이미지는 실제 메뉴 및 매장 사진이 아니므로 실제 영업용 사이트로 전환하기 전에 반드시 실제 사진으로 교체한다.

다른 접근으로 이미지 없는 색상 플레이스홀더 또는 축약형 랜딩 페이지를 검토했지만, 기존 브랜드 설계의 완성도를 검증하기 어렵기 때문에 채택하지 않았다.

## 페이지 구조

단일 공개 페이지를 다음 순서로 구성한다.

1. 상단 내비게이션
   - 브랜드명, 이야기, 메뉴, 맛있게 즐기는 법, 오시는 길
   - 데스크톱 예약 버튼
   - 모바일 메뉴는 페이지 내 섹션 이동 링크를 펼치는 방식
2. 히어로
   - 청주 봉명동 샤브형 등갈비찜 소개
   - 핵심 문구, 예약 및 전화 버튼, 예약 혜택
   - 대표 음식 이미지
3. 신뢰 정보
   - 네이버 별점과 리뷰 수, 좌석 규모, 포장·예약·주차 여부
4. 브랜드 이야기
   - 어머니의 마음을 담은 소개 문구와 따뜻한 한식당 이미지
5. 맛있게 즐기는 법
   - 끓이기, 재료 고르기, 함께 익히기, 빙수로 마무리하기의 네 단계
6. 대표 메뉴
   - 매운 등갈비찜 세트와 간장 등갈비찜 세트
   - 가격, 구성 설명, 테스트용 메뉴 이미지
7. 공간과 모임
   - 좌석 규모와 단체석 안내
   - 테스트용 매장 이미지
8. 자주 묻는 질문
   - 맵기, 단체 예약, 주차, 포장·배달 안내
9. 방문 정보
   - 주소, 영업시간, 전화번호, 주차·대중교통 정보
   - 예약 및 길찾기 버튼
10. 푸터와 모바일 고정 작업 버튼
   - 전화, 길찾기, 예약

## 시각 체계

- 고추장 빨강 `#9F2F1F`: 핵심 CTA와 강조
- 먹색 `#2A2520`: 제목, 방문 정보 배경, 푸터 강조
- 황토색 `#F4E4C8`: 주 배경
- 쌀빛 `#FFF8EA`: 카드 및 밝은 표면
- 한지색 `#F7EEDC`: 교차 섹션과 보조 카드
- 볏짚색 `#D8B86A`: 따뜻한 강조
- 본문 갈색 `#3A3028`, 보조 갈색 `#6F6258`
- 경계선 `#D9C3A3`, 채소색 `#496B3A`

본문은 최소 16px, 기본 18px로 유지한다. 버튼 높이는 최소 48px, 주요 CTA는 52~56px로 만든다. 카드 모서리는 8px을 기본으로 하며 과도한 그림자와 둥근 모서리를 피한다.

## 반응형 동작

- 1024px 이상: 최대 1200px 콘텐츠 폭, 2~4열 구성
- 640px~1023px: 2열 중심의 태블릿 구성
- 639px 이하: 단일 열, 전체 너비 CTA, 하단 고정 작업 버튼
- 내비게이션 링크는 각 섹션의 `id`로 부드럽게 이동한다.
- 모바일 고정 버튼은 본문 및 방문 정보와 겹치지 않도록 하단 여백을 확보한다.

## 이미지 자산

다음 테스트용 이미지를 제작한다.

- 김이 오르는 매운 등갈비찜 대표 이미지
- 따뜻한 황토·목재 분위기의 한식당 내부 이미지
- 간장 등갈비찜 메뉴 이미지
- 가족 및 단체 식사가 가능한 좌석 이미지

이미지에는 글자, 로고, 가격표를 넣지 않는다. 음식과 공간을 과장 광고로 오인하지 않도록 대체 텍스트와 코드 주석에서 테스트용 이미지임을 명확히 한다. 실제 영업 전 실제 매장 사진으로 교체한다.

## 링크 및 데이터

- 전화 버튼: `tel:050714490004`
- 네이버 예약과 길찾기: 정확한 네이버 플레이스 URL을 받기 전까지 매장명과 주소를 포함한 네이버 검색 URL 사용
- 외부 링크는 새 탭에서 열고 안전한 `rel` 속성을 사용
- 주소: 충북 청주시 흥덕구 백봉로 213-1 1층
- 영업시간과 메뉴 가격은 Pencil 초안의 값을 사용

## 기술 구조

- `app/page.tsx`: 정적 콘텐츠 데이터와 페이지 섹션 조합
- `app/globals.css`: 브랜드 토큰, 레이아웃, 반응형 스타일, 상호작용 스타일
- `app/layout.tsx`: 한국어 문서 설정, 메타데이터, 글꼴 설정
- `public/images/`: 테스트용 이미지 자산
- `lucide-react`: 전화, 지도, 시계, 주차 등 일관된 아이콘

현재 페이지는 정적 생성한다. 데이터베이스, 로그인, 관리자 API, 결제, 예약 API 연동은 포함하지 않는다.

## 오류 및 대체 동작

- 이미지 로드 실패 시 브랜드 배경색이 남아 레이아웃이 무너지지 않게 한다.
- 외부 네이버 링크가 변경되더라도 전화번호와 주소는 페이지에 그대로 표시한다.
- JavaScript가 비활성화돼도 주요 콘텐츠와 전화 링크는 사용할 수 있어야 한다.
- 모바일 메뉴 버튼은 접근 가능한 이름과 상태를 제공한다.

## 검증 기준

- `pnpm lint` 통과
- `pnpm build` 통과
- `/`가 정적 페이지로 생성됨
- 390px, 768px, 1440px에서 가로 스크롤과 콘텐츠 겹침이 없음
- 내비게이션과 모바일 고정 버튼의 터치 대상이 48px 이상
- 전화 링크와 섹션 이동 링크가 올바름
- 페이지 제목, 설명, 한국어 `lang` 속성이 설정됨
- GitHub 푸시 후 Vercel 운영 배포가 `READY` 상태이고 공개 URL이 HTTP 200을 반환함

## 범위 제외

- 관리자 로그인 및 대시보드
- 실제 예약 접수, 결제, 회원가입, 데이터베이스
- 네이버 플레이스 API 또는 지도 API 임베드
- 실제 매장 사진 촬영 및 보정
- 사업용 전환과 Vercel Pro 변경
